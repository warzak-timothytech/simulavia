# SimulaVia (Protótipo v0.1)

Simulador web interativo de convivência e micromobilidade urbana (patinetes elétricos, bicicletas elétricas, pedestres e carros), com cenário piloto em **Guaíba, RS**.

> **Aviso:** Este projeto é um protótipo exploratório e educativo baseado em dados abertos (`© OpenStreetMap contributors`) e regras gerais de trânsito (CTB / Resolução CONTRAN 996). Não constitui laudo técnico ou projeto oficial de engenharia.
